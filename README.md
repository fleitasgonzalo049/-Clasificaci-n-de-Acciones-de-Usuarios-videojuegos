¿De qué trata este proyecto?

En este trabajo exploramos cómo analizar y clasificar el comportamiento de los jugadores dentro de una plataforma de videojuegos utilizando Python.

A partir de un conjunto de datos simple —donde registramos qué hace cada usuario, cuánto tiempo le lleva y qué resultado obtiene— armamos un primer sistema de reglas lógicas (if-then). La idea fue simular cómo categorizaríamos estas acciones "a mano" según el criterio del negocio.

Más allá del código, el objetivo principal fue hacer el ejercicio reflexivo: entender la brecha que hay entre definir reglas manuales para clasificar datos y dar el salto hacia el aprendizaje supervisado, donde dejamos que los algoritmos de Machine Learning descubran esos patrones por sí mismos.
